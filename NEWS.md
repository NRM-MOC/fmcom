# fmcom 0.3.0

* Added 2024 data (7,554 new records from marine and freshwater stations). The dataset now covers 1967-2024.

* Added the data pipeline used to build the dataset to `data-raw/`: it downloads
  new data and appends it to the previous version (see `data-raw/README.md`).

# fmcom 0.2.0

* Initial version: marine (MCoM) and freshwater data combined, with new `water_type` column. The datsets had 366,600 records.
